## A lógica (Fórmula de Lançamento enxuta)

Quatro fases. PLF cortada ao osso: **entregar valor antes de pedir a venda**, e só abrir o carrinho depois de aquecer.

```
FASE 0            FASE 1                    FASE 2              FASE 3
Aquecimento  →    Pré-lançamento (3 CPLs) → Abertura           Fechamento
(já rodando)      Oportunidade              (carrinho aberto)  (escassez real)
grupo + quiz      Transformação                                 → Pós-venda
+ lista           Método/mentor
```

- **CPL = Conteúdo de Pré-Lançamento.** Três entregas de valor, cada uma resolvendo uma objeção e aumentando o desejo.
- **Carrinho aberto ~5 dias.** Mais que isso esfria, menos que isso corre.
- **Dois canais, um calendário.** Email = versão longa. WhatsApp = versão curta com link. Grupo aberto recebe só os 3 avisos-chave.

## Camada de copy — como cada disparo foi construído

**Jeff Walker (PLF)** é a espinha: valor em 3 CPLs, depois abre e fecha o carrinho como um evento com prazo.

**Gary Halbert (Boron Letters)** é o jeito de escrever cada peça:
- Escreve pra **uma** pessoa (tudo no singular, com o nome).
- A primeira linha tem um único trabalho: fazer ler a segunda. Frase curta, gancho concreto.
- Palavra simples, frase curta, parágrafo de uma ideia, muito espaço em branco.
- Vende o **resultado e a emoção**, não a funcionalidade.
- O assunto do email é o porteiro: se não abrir, o resto não existe (pilha A vs pilha B).
- O **P.S.** é a segunda coisa mais lida — sempre reforça a oferta ou o prazo.

**Robert Cialdini** são os gatilhos, na ordem em que aparecem sozinhos (sem forçar):
